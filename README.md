# [Project title]

This repository contains the source code for the VR program in "Functional motor congruency and spatial context during second language vocabulary learning: an experimental VR design", 2026. The study builds on Rudling et al. (2026) and Rumetshofer et al. (2026).

## Requirements

- Unity 6000.6.2f1 (install via Unity Hub, with the **Android Build Support** module)
- Meta Quest 3 with developer mode enabled
- Unity packages (installed automatically via the Package Manager when the project is opened):
  - ProBuilder 6.1.2
  - XR Interaction Toolkit 3.6.1

## Setup

1. Clone the repository:
   ```
   git clone [repo URL]
   ```
2. Open the project in Unity Hub using Unity 6000.6.2f1.
3. Import the third-party assets that are not included in this repository (see [Third-party assets](#third-party-assets)):
   - POLYGON – Starter Pack (Synty) from the Unity Asset Store
   - Unity Particle Pack from the Unity Asset Store
